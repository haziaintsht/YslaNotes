# 📖 YslaNotes

AI-powered flashcard and study-quiz app. Upload a PDF/DOCX/TXT and generate flashcards, multiple-choice, or situational questions — or build modules manually. Built with Node.js, Express, Supabase, and Gemini AI.

## Setup

```bash
npm install
cp .env.example .env   # fill in your Supabase, Gemini, and login credentials
npm start
```

Then run `schema.sql` in your Supabase project's SQL Editor to create the database tables, and visit **http://localhost:3000**.
